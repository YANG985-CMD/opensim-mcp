# 完工即关窗

这是默认建模流程，不是后台定时清理。

1. 显式指定文档并使用最新状态，完成一个零件的原生几何、必要检查和所需导出。
2. 阶段保存继续使用 `sw_save(..., close_when_finished=False)`；不能每加一条特征就关窗。
3. 零件完工使用 `sw_save(..., close_when_finished=True)`。先验证原生保存、文件与哈希，再检查关窗条件，最后只关闭这个零件窗口。
4. 阅读返回的 `window_cleanup`。成功时 `window_closed=True`。若零件仍被总成引用，保留其引用数据，核对父装配引用、配置、位姿、配合与未保存标志不变。
5. 未被引用的零件卸载后，`document_handle_valid=False`、`state=None`；保存时的旧状态放在 `saved_state`，只供记录。下次编辑必须重新打开取得新句柄。
6. 当前总成保留供用户审阅；暂时不用的总成按确切文档保存核对后再显式关闭，不批量关闭用户窗口。

## 保留规则

- 隐藏未保存文档存在时，保存成功但暂不关窗，返回阻挡原因；不隐式保存其他文档、不丢弃内容。
- 保存后目标又出现新修改或状态变化时，保留窗口，明确返回原因。
- 原生关闭返回异常、窗口仍可见、父装配变化或磁盘哈希变化时，明确报告 `FINISH_WINDOW_PARTIAL` 和 `native_save_succeeded=True`。先只读检查，不能把整个保存动作自动重放。
- 不结束程序、不自动重启 SolidWorks、不降低内存保护阈值，不因内存不足改写源文件或合并独立零件。
- 关闭窗口并不保证模型缓存全部释放；被装配引用的数据仍需保留。返回关窗前后物理内存与提交内存余量，不能把“窗口关了”说成“缓存已清空”。

需要保留某个零件窗口供用户查看时，以用户明确要求优先，并说明保留原因。完工保存关窗不是几何、强度或可打印性验收。
