# Delivered scope and next work

v0.4 implements the five requested areas within explicit, tested profiles:

1. Isolated asynchronous native workflows, real phase/log progress, whole-process-tree cancellation,
   durable history and model/pose/time checkpoints. Arbitrary persistent Python variables are outside checkpoint scope.
2. Installed API/member discovery, paginated component properties/sockets, non-executing syntax/symbol checks and traceback locations.
3. MCP PNG content, standalone SVG curves/native pose geometry, Navigator selection, structured parameter undo/redo and GUI pose undo.
4. Native manual/marker-pair scaling, force-aware JointReaction, fixed-time control-effort Moco and independent marker residual assessment.
5. Official Gait2354 measured-data regression, force plates, 4.6/4.3 model serialization/ID comparison and GUI lifecycle checks.

Next work is broader coverage: additional published datasets and GUI releases, MarkerPlacer,
structured MocoTrack/MocoInverse/custom goals, explicit reserve/residual and contact configurations,
dependency manifests, richer 3D viewer exports, topology editing transactions and complete edit journals.
These are separate extensions rather than claims made by the current tests.
