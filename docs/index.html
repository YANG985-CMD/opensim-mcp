SolidWorks MCP

建模、改尺寸、装配配合、干涉和间隙检查、质量参数与模型导出。

准备 SOLIDWORKS 2025 与 64 位 Python 3.12。

下载 Windows 安装包
查看安装步骤
  1. 核对同一 Release 中的 SHA256。
  2. 解压到最终目录。
  3. 运行 install.ps1，等到 MCP_READY。
  4. 保留生成的设置文件，并连接已运行的软件。

OpenSim MCP

检查和编辑人体模型，计算运动与受力，导出带曲线的 HTML 三维结果。

Windows 11 x64。安装器准备 Python 与 API，GUI 可选。

下载 Windows 安装包
查看安装步骤
  1. 核对同一 Release 中的 SHA256。
  2. 解压后进入内层 opensim-mcp。
  3. 运行 install.cmd，完成联网安装与自检。
  4. 配置需要访问的项目输入和结果目录。

配置助手

填入本机路径，生成 Codex 配置。

先完成安装，再核对下方示例路径。配置在浏览器本地生成，下载后合并到已有的 config.toml。

该目录中应有 .venv 和 .api46-venv。 该目录中应有 launch.py 和安装生成的设置文件。 官方安装器用户请填它实际生成的服务路径。

使用安装器已生成的 MATLAB 扩展参数时，将其保留在 matlab 条目中。完整指南解释了两种配置方式。

Codex · TOML
